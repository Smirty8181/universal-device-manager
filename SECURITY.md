# Безопасность

## Как сообщить об уязвимости

Откройте приватный отчёт через GitHub Security Advisories в репозитории проекта. Публичные issue для уязвимостей не создавайте.

В отчёте укажите версию, шаги воспроизведения и ожидаемое поведение. Не прикладывайте персональные данные, токены и содержимое чужих устройств. Ответ — в течение недели.

## Модель угроз

UDM работает в пользовательской сессии и не требует прав администратора для обычной работы. Приложение читает данные устройств через SetupAPI, HID и Bluetooth, управляет громкостью и отправляет ввод через `SendInput`.

Что приложение делает и чего не делает:

- не хранит OAuth-токены и пароли; в настройках лежат только параметры интерфейса и профили;
- не выполняет команды из конфигурационных файлов и не запускает внешние процессы по данным из БД;
- не устанавливает драйверы без явного подтверждения и предварительной проверки подписи INF;
- не изменяет прошивки;
- не перехватывает и не блокирует ввод: визуализатор клавиатуры использует Raw Input в режиме наблюдения и отключается вместе со своим экраном;
- не записывает нажатия в журнал, не читает буфер обмена и не отправляет ввод в сеть;
- не обходит античиты: Auto Clicker — это обычный `SendInput`, игра вправе его не принимать.

## Права и UAC

Установщик ставится в профиль пользователя (`currentUser`) и не запрашивает повышение. Для установки драйверов и части операций с оборудованием Windows может показать собственный запрос UAC — это системное требование, а не запрос приложения.

## Целостность обновлений

Автообновление не реализовано. Релизы собираются CI из тега, артефакты подписаны ключом подписи Tauri, если он настроен в секретах репозитория. Скачивайте сборки только из раздела Releases этого репозитория.

## Ограничения

Приложение не является средством защиты. Оно не проверяет прошивки устройств и не гарантирует, что стороннее оборудование ведёт себя ожидаемо. Для неизвестных вендоров включаются только стандартные механизмы Windows.
