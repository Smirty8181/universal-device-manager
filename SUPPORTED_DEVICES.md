# Поддерживаемые устройства

UDM не ограничен списком моделей: обнаружение, стандартный заряд, громкость, ремап, макросы, визуализатор и автокликер работают на системном уровне для любого совместимого устройства Windows. Список ниже фиксирует только то, что реально проверялось.

## Проверено на оборудовании

| Устройство | VID:PID | Подключение | Что работает | Ограничения |
|------------|---------|-------------|--------------|-------------|
| Red Square Alumix TKL | 342D:E410 / 342D:E411 | 2.4 ГГц ресивер RSQ_20055_2.4G | обнаружение, подсветка (эффект, яркость, скорость, цвет) с подтверждением чтением | заряд не отдаётся; прошивка не обновляется |
| AJAZZ AJ159 NL | 7768:6426 | NearLink 2.4 ГГц | заряд (vendor HID), DPI-этапы, polling rate, системные кнопки | LOD, debounce, angle и onboard-профили без документированного протокола |
| IO Graphite 2 Pro Wireless | 4C4A:4155 | USB-ресивер | обнаружение, громкость и mute через Windows, микрофон | ресивер не отдаёт заряд; фирменный RGB не подтверждён |
| fifine Microphone | — | USB | запись/громкость через Windows, выбор устройства | фирменные эффекты не управляются |

Для этих устройств в карточках показываются реальные изображения. Для остальных используется нейтральная заглушка без выдачи за конкретную модель.

## Универсальные категории

Работают через Windows без фирменных протоколов:

- клавиатуры и мыши (USB, Bluetooth, 2.4 ГГц);
- гарнитуры и наушники (аудиоэндпоинты Windows);
- микрофоны;
- геймпады и контроллеры (как HID-устройства);
- веб-камеры и мониторы (обнаружение, если Windows отдаёт устройство);
- составные HID-устройства с несколькими интерфейсами.

Доступность заряда зависит от устройства:

- BLE Battery Service (0x180F/0x2A19);
- HID Battery Strength (usage page 0x06, usage 0x20);
- vendor-отчёт, если протокол проверен.

Если ни один источник не отвечает, UDM не показывает процент и объясняет причину. Это не ошибка приложения.

## Фирменные функции

| Функция | Статус |
|---------|--------|
| Подсветка Alumix | подтверждена записью и чтением |
| DPI/polling AJAZZ | подтверждены записью и чтением |
| Подсветка прочих устройств | нет проверенного протокола — управление отключено |
| Заряд Alumix / Graphite | недоступен через доступные интерфейсы |
| Battery RGB | движок готов; нужен аппарат с зарядом и подтверждённой RGB |
| Прошивки | только при официальном способе восстановления |

## Как добавить устройство

1. Подключите устройство и откройте «Инспектор протоколов» / «Диагностику».
2. Экспортируйте отчёт: VID, PID, Hardware ID, HID-дескрипторы, интерфейсы.
3. Для нового протокола нужны публичная документация или обратная разработка в режиме только чтения.
4. Добавьте адаптер и запись в базу, проверьте на живом устройстве и оформите pull request.

Не добавляйте модель в список поддерживаемых без проверки записи и чтения: интерфейс не должен показывать неработающие регуляторы.
