# Установка UDM

## Установщик

1. Скачайте `Universal Device Manager_<version>_x64-setup.exe` из Releases.
2. Запустите файл. Установка выполняется для текущего пользователя, без UAC.
3. Запустите UDM из меню «Пуск».

Ярлык и деинсталлятор создаются автоматически. Настройки, профили и история сохраняются в `%APPDATA%\com.udm.desktop`.

## Portable

1. Распакуйте `UDM-<version>-win-x64.zip` в любую папку.
2. Запустите `Universal Device Manager.exe`.

Для переноса настроек скопируйте папку `%APPDATA%\com.udm.desktop` на другую машину. База и история не содержат персональных данных.

## Права администратора

Обычная работа не требует прав администратора. Повышение UAC запрашивается только при установке драйвера из Центра драйверов — после явного подтверждения. Автокликер, визуализатор и настройки устройств работают без elevation.

## Удаление

Параметры Windows → Приложения → Universal Device Manager → Удалить.

Данные в `%APPDATA%\com.udm.desktop` не удаляются автоматически: там история заряда, профили и логи. Удалите папку вручную, если они не нужны.

## Первый запуск

- Разрешите приложению прочитать список устройств (UAC не нужен).
- Откройте «Мои устройства» и нажмите «Пересканировать», если список пуст.
- Для заряда на беспроводной мыши/гарнитуре убедитесь, что устройство подключено и Windows видит его батарею.
- Для подсветки и DPI откройте карточку устройства: доступные функции отмечены, недоступные объяснены.

## WebView2

На Windows 11 WebView2 установлен по умолчанию. На Windows 10 при ошибке запуска установите WebView2 Runtime с сайта Microsoft.
